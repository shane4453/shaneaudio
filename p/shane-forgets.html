Shane Forgets

Degrading Memory Effect

Download Free

No signup. Direct download.

A delay that misremembers. Each repeat isn't a quieter copy — it's a slightly wrong one, and the errors accumulate.

The signature is that the energy stays but the correlation falls apart. The repeats keep their level and their rough shape while the detail inside them drifts away from the original, the way a memory does. Freeze it and it will sit there forgetting in place.

CONTROLS below. Sync it to the project or run it free.
CONTROLS
· TIME · TIME SYNC · TIME DIVISION   free, or locked to the host
· RECALL     how much of the original survives each pass
· REWRITE    how much gets replaced with something else
· FADE       how fast it lets go
· FREEZE     stops taking new input and keeps forgetting
· MIX
