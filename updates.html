Updates

What changed, and when. Every update is free for existing owners.

  1. 2026-11-07

    v1.6.2 - two weeks of going through every plugin

    • Every plugin was opened one at a time and measured. What follows is the pattern; the per-plugin list is on each plugin page.
    • A crash is fixed that could take the host down with it: closing a plugin window and then removing the plugin left a timer running on memory that had already been freed.
    • Instruments: overlapping notes on the same key no longer cut each other off, and the sustain pedal now works on the sampled instruments, where it had no effect at all.
    • Effects: Mix, Bypass and section switches now cross over 10 ms instead of stepping once per block, so automating them no longer clicks. Engines keep running while bypassed, so a reverb tail survives the switch.
    • Factory presets are now deterministic across 17 plugins. They were partial, so a preset kept values from whichever preset you loaded before it.
    • Reported latency corrected where it was wrong - Shane Limiter was declaring 11 of its 16 samples - which had pulled parallel tracks out of line.
    • Licence activation fixed: a bundle key now counts one activation per computer instead of one per plugin, so one key covers five machines as stated.
    • All 44 plugins rebuilt, re-signed and notarized for macOS (Universal) and Windows. Free for existing owners - re-download from your Gumroad library.
  2. 2026-09-22

    v1.6.1 - trials are now per plugin

    • Every plugin now has its own seven-day trial. Before this, one trial covered the whole suite: three days with any plugin ended it for all the others, so trying one meant losing the chance to hear the rest.
    • Shane Analog Delay: CHARACTER is now on the panel - the control existed but had no place in the interface. Shane EQ: the COLOR list no longer truncates. Shane DS: LAW labels no longer overlap.
    • Shane BusComp: the VU needle stays inside the meter window. Shane 73: knob pointers move cleanly against the printed scale.
    • Free plugins: a link to the rest of the suite in the preset menu.
    • All 44 plugins rebuilt, re-signed and notarized for macOS (Universal) and Windows. Free for existing owners - re-download from your Gumroad library.
  3. 2026-09-18

    v1.6 - every plugin updated

    • Shane FET: detector rebuilt from a measured step table of a classic FET compressor. Shane EQ: COLOR mode with seven reference mastering-EQ curves plus two vintage tube-EQ models.
    • Shane BusComp: manual release times were 10x too slow - fixed; knee measured from a console bus compressor reference. Shane TubeComp: even harmonics restored; front-panel knobs now turn as one piece with the panel art.
    • Shane Multi: a new detector mode with measured ballistics. Shane Limiter: six measured release modes. Shane DS: a constant-reduction de-essing mode. Shane Analog Delay: measured character section. Shane Dist: odd/even voicing fixed.
    • Shane Autotune: intermittent clicks fixed (MIX is now the correction amount). Shane EP: onset latency 350 ms to under 7 ms. Shane 60: every preset on the octave.
    • All 44 plugins rebuilt, re-signed and notarized for macOS (Universal) and Windows. Free for existing owners - re-download from your Gumroad library.
  4. 2026-09-04

    Shane Tape 424 v1.5

    • New LOW LATENCY switch: 24 ms → 4 ms (192 samples at 48 kHz). Wow and flutter unchanged; only heavy PITCH settings get slightly grainier. Added because a user asked for it.
    • Windows zip now ships with an installer (Install.bat) that places both VST3 and AAX.
  5. 2026-09-03

    Official site

    • shaneaudio is live — every plugin has its own page here, with the store used only for checkout.
  6. 2026-09-01

    Seven new releases

    • Shane Tune 2.0 (note editor), Shane Autotune, Shane DS, Shane Multi, Shane 73, Shane CX and Shane Moogybass are out on macOS and Windows.
  7. 2026-08-28

    v1.4 across the suite

    • Licence registration and a built-in trial in every paid plugin. Rebuilt, re-signed and notarized for macOS and Windows.
